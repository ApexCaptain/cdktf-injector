    Class TerraformInjectorClass

    Implementation behind TerraformInjector and TerraformInjectorAsync. One instance per scope, created by TerraformInjectorFactory. Registration methods only record containers; nothing is instantiated until inject().

      Lazily provide elements to the injector.

      The configure callback returns a list of nested element configs (or [configs, shared]). When the lazy element is injected, each entry is provided to this injector as a sibling element of nestedTerraformElementClass with its own id, so the number of elements can depend on other elements. Access them through element.nested.

    • setDefaultConfigure(

              id: string,
              className: string,
              description?: string,

      ): TerraformInjectorClass

      Set a default config that is deep-merged into every element provided under this scope, including elements of nested injectors.

      Merge order is outermost scope first, then inner scopes, then the element's own config, so the more specific value wins. Arrays are replaced, not concatenated. TerraformOutput and elements provided with useDefaultConfig = false are skipped.
