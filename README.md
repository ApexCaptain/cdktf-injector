# Dependency Injection for CDKTF

`cdktf-injector` is a dependency injection library for [CDKTF][cdktf] ([AWS Cloud Development Kit][cdk] for [Terraform]).

If you are not familiar with [cdktf] and [terraform] yet or haven't heard of them before, this library may not be that so useful. That's totally cool, but I recommend you to have a look what they ([cdktf] and [terraform]) are or at least what's the concept of [IaC]. Those are really amazing.

**There are two prerequisites for cdktf-injector**

- [Terraform][terraform] - Terraform must be on your `PATH`. See the [Terraform install guide](https://developer.hashicorp.com/terraform/install).

- [cdktf] - A library for defining [Terraform] resources using programming constructs. Click [here](https://github.com/hashicorp/terraform-cdk/blob/main/docs/getting-started/typescript.md) to get started. Or, simply type the following lines.
  ```sh
  mkdir your-project-name
  cd your-project-name
  npx cdktf-cli init --template="typescript" --local
  ```
  <br>

## Features

- **No decorator**
- **No need to declare custom classes**
- **No need to explicitly write dependencies**

<br>

## Installation

### Using [npm](https://www.npmjs.com/)

```sh
npm install cdktf-injector --save
```

### Using [pnpm](https://pnpm.io/)

```sh
pnpm add cdktf-injector
```

### Using [yarn](https://yarnpkg.com/)

```sh
yarn add cdktf-injector
```

### Requirements

| Package                                                       | Version          |
| ------------------------------------------------------------- | ---------------- |
| [Node.js](https://nodejs.org/)                                | `>= 22`          |
| [cdktf] (peer)                                                | `>=0.20.3 <0.22` |
| [constructs](https://www.npmjs.com/package/constructs) (peer) | `^10.3.0`        |

> **Note** : [cdktf] supports multiple languages, such as `TypeScript`, `Python`, `Java`, `C#` and `Go`. However, according to [Typescript restriction of jsii](https://aws.github.io/jsii/user-guides/lib-author/typescript-restrictions/), which I originally wanted to use to power my lib and what [cdktf] depends on, it does not allow using `Parameterized Types(aka: Generics)`. And as far as I know, there is no other decent way to implement dependency injection without using generics or decorators. In brief, `cdktf-injector` is currently available only in [Node.js](https://nodejs.org/) env. I'm looking forward to making this lib support multiple languages soon.

## Development

The project is managed by [projen](https://github.com/projen/projen) with pnpm. Edit `.projenrc.ts` and run `pnpm projen` instead of editing generated files (`package.json`, `tsconfig*.json`, workflows, ...).

```sh
pnpm install
pnpm build   # compile, test, package
pnpm test    # jest + eslint
pnpm docgen  # TypeDoc into docs/
```

The devcontainer (`.devcontainer/`) installs Node.js and Terraform (via the `ghcr.io/devcontainers/features/terraform` feature).

`docs/` is TypeDoc output regenerated by `pnpm docgen`; do not edit it by hand. Work items are tracked as markdown under `issues/`, not GitHub Issues.
